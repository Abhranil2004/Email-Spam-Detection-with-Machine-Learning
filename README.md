## 🧠 Problem Statement

Email spam continues to pose a significant challenge in the digital communication space. From phishing attacks to irrelevant advertisements, spam emails compromise user experience and security.

This internship project under **Edunet Foundation** focuses on building an intelligent spam detection system using **Python** and **Machine Learning** to differentiate between legitimate (ham) and spam messages.

### 🎯 Objectives:

- Preprocess and clean a raw email dataset  
- Engineer features relevant to spam detection  
- Build and evaluate machine learning models  
- Tune hyperparameters for better performance  
- Validate model generalizability through cross-validation  
- Discuss real-world deployment and ethical handling of data  

---

## 🗂️ Project Summary

This project involved the end-to-end development of an email spam detection model using techniques like:

- **Exploratory Data Analysis (EDA)**  
- **TF-IDF Vectorization**  
- **Multinomial Naive Bayes Classifier**  
- **Evaluation Metrics** (Accuracy, Precision, Recall, F1-Score)

The model achieved a **98.49% recall** on the test set, proving its effectiveness at identifying spam messages while minimizing false negatives.
